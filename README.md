# Clothing Shop Sales and Customer Feedback Assistant

This repository implements AI for Everyone Project 02 using the supplied `Project_02` dataset pack.

## Important project limits
- Sales rows are generated classroom scenarios, not real shop transactions. Demand predictions are demonstration estimates, not confirmed forecasts.
- KMeans groups are product-planning scenarios, not customer segments.
- The CNN supports only `top`, `trouser`, and `bag`; Fashion-MNIST examples do not establish performance on phone photos or multiple garments.
- NLTK VADER and topic rules use the supplied English teaching comments. They are not a real customer survey.
- The Streamlit app loads saved models only. It never trains models after a user clicks a button.
- Offline summary works without an API key. Groq is optional and must remain on its free plan.

## Train and build in Google Colab
1. Open `Clothing_Shop_Full_Workflow.ipynb` in Google Colab.
2. Upload the instructor-supplied `AI_for_Everyone_Ready_Datasets.zip` when prompted.
3. Run every cell from top to bottom.
4. The notebook trains the Decision Tree, three-group KMeans model, and three-epoch CNN; evaluates the supplied feedback with VADER; saves model files and runtime versions; checks the repository structure; and downloads `Clothing-Shop-Deployment.zip`.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Optional Groq Secrets
In Streamlit Community Cloud → App → Settings → Secrets, add:
```toml
GROQ_API_KEY = "your-key"
GROQ_MODEL = "openai/gpt-oss-20b"
```
Check the current model availability and free quota in your Groq account. Do not enable paid billing. The app remains usable in Offline summary mode without a key.

## Deployment
Upload the contents of the extracted deployment ZIP to a GitHub repository. Connect that repository to Streamlit Community Cloud and select `app.py`. Keep the pinned scikit-learn and TensorFlow CPU versions generated by the notebook; the saved model files must be loaded with compatible library versions.
